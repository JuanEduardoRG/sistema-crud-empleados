
# Sistema de gestión de empleados

Aplicación web CRUD desarrollada con Python, Flask y SQL Server para administrar registros de empleados.

## Funcionalidades

- Registrar empleados.
- Consultar empleados registrados.
- Editar información de empleados.
- Eliminar empleados.
- Almacenar la información en SQL Server.

## Tecnologías

- Python
- Flask
- pyodbc
- Microsoft SQL Server
- HTML y CSS

## Requisitos

- Python instalado.
- Microsoft SQL Server.
- ODBC Driver para SQL Server.
- Git.

## Instalación

1. Clonar o descargar este repositorio.
2. Crear un entorno virtual de Python.
3. Instalar las dependencias con `pip install -r requirements.txt`.
4. Crear la base de datos y la tabla siguiendo las instrucciones del proyecto.
5. Configurar la conexión a SQL Server con los datos de la instalación local.
6. Ejecutar la aplicación Flask.

## Estado del proyecto

Proyecto de aprendizaje para practicar desarrollo web backend, operaciones CRUD y conexión con bases de datos relacionales.
